# कोण आहे इम्पोस्टर? 🎭

मराठी ऑनलाइन मल्टीप्लेअर पार्टी गेम (३–१५ खेळाडू). Node.js + WebSocket + SQLite.

## तांत्रिक रचना
- `server/index.js` — HTTP + WebSocket सर्व्हर, सुरक्षा हेडर्स, दर-मर्यादा
- `server/game.js` — सर्व गेम नियम (सर्व्हर-अधिकृत): खोल्या, भूमिका, संकेत, मतदान, गुण, पुन्हा जोडणी
- `server/words.js` — मराठी शब्द जोड्या (१८ श्रेणी, २०६ जोड्या, ४१२ शब्द)
- `server/db.js` — SQLite साठवण (खोल्या, खेळाडू, गुण)
- `public/` — मोबाइल-फर्स्ट मराठी UI
- `test/` — स्वयंचलित चाचण्या

## संगणकावर चालवणे
```
npm install
npm start          # http://localhost:3000
npm test           # सर्व्हर चाचण्या
```
Node.js 22.13 किंवा नवीन हवे (अंगभूत `node:sqlite` वापरतो).

## तैनाती (Deployment)
गेमला सतत चालणारा सर्व्हर + WebSocket + कायमची डिस्क हवी. फक्त-स्टॅटिक होस्टिंग (GitHub Pages, Netlify, Vercel) चालणार नाही.

**Fly.io (शिफारस):** `fly.toml` तयार आहे.
1. `fly launch --copy-config --no-deploy`
2. `fly volumes create gamedata --size 1 --region bom`
3. `fly deploy`

**Render (मोफत):** `render.yaml` व `Dockerfile` तयार आहेत.
1. सर्व फाईल्स GitHub repository मध्ये ठेवा.
2. render.com → **New → Blueprint** → repository निवडा → **Apply**. (किंवा **New → Web Service**, Language: Docker, Instance type: Free.)
3. ५–८ मिनिटांत `https://…onrender.com` URL मिळतो.
- मोफत प्लॅनवर १५ मिनिटे वापर नसल्यास सर्व्हर झोपतो (पुन्हा उघडायला ~१ मिनिट), आणि डिस्क नसल्याने खोल्या/गुण पुसले जातात. पेड प्लॅन + Disk (`/data`, `DATA_DIR=/data`) घेतल्यास ते टिकतात.

HTTPS आपोआप मिळतो; WebSocket `wss://` वर चालतो.

## पर्यावरण चल
| नाव | अर्थ |
|---|---|
| `PORT` | पोर्ट (डिफॉल्ट 3000) |
| `DATA_DIR` | डेटाबेस फोल्डर (डिफॉल्ट `./data`) |
| `ADMIN_KEY` | सेट केल्यास `/api/admin/stats?key=…` वर आकडेवारी दिसते |
| `ALLOWED_ORIGINS` | अतिरिक्त परवानगीचे डोमेन (स्वल्पविरामाने) |

## गेम अॅडमिनिस्ट्रेटर सूचना
- **खेळ घेणे:** होस्ट "नवीन खोली" बनवतो, WhatsApp बटणाने आमंत्रण पाठवतो. किमान ३ खेळाडू ऑनलाइन हवेत.
- **होस्टचे अधिकार:** इम्पोस्टर संख्या, श्रेणी, चर्चेचा वेळ, संकेत फेऱ्या, शेवटची संधी; खेळाडूला काढणे; मतदान लगेच सुरू करणे; पुढची फेरी.
- **गुण:** निर्दोष जिंकल्यास +१०; इम्पोस्टर जिंकल्यास प्रत्येक इम्पोस्टरला +२०; इम्पोस्टरला योग्य मत दिल्यास +५.
- **बरोबरी:** पहिल्यांदा बरोबरीतील खेळाडूंमध्ये पुन्हा मतदान; पुन्हा बरोबरी झाल्यास इम्पोस्टर जिंकतात.
- **डिस्कनेक्ट:** खेळाडू त्याच फोनवर पान उघडताच परत जोडला जातो. होस्ट २० सेकंद गेल्यास होस्टपद दुसऱ्याला जाते. जिवंत खेळाडू ३ पेक्षा कमी झाल्यास ४५ सेकंदांनी फेरी रद्द.
- **खोल्या:** ६ तास कोणी नसल्यास खोली काढली जाते. सर्व्हर रीस्टार्टनंतर गुण टिकतात.
- **आकडेवारी:** `ADMIN_KEY` सेट करून `/api/admin/stats?key=तुमची_किल्ली`.
- **बॅकअप:** `DATA_DIR/game.db` फाईल कॉपी करा.
